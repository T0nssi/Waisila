# เว็บไซต์ธุรกิจพื้นอีพ็อกซี่ — คู่มือติดตั้งและแก้ไข

เว็บไซต์นี้เป็น **HTML ล้วน ไม่มีขั้นตอน build ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล**
มีแค่ 3 ไฟล์ ทำให้เผยแพร่ได้ฟรีและโหลดเร็วบนมือถือ 4G

```
epoxy-site/
├── index.html    ← เนื้อหาทั้งหมดอยู่ในไฟล์นี้
├── styles.css    ← สี ฟอนต์ ระยะห่าง (แก้สีแบรนด์ได้ที่บล็อก :root ด้านบนสุด)
├── main.js       ← เมนูมือถือ + การตรวจสอบฟอร์ม
└── assets/       ← ใส่รูปผลงานจริงที่นี่
```

---

## 1. ทดลองเปิดดูในเครื่อง

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือถ้าต้องการให้เหมือนของจริง:

```bash
cd epoxy-site
python3 -m http.server 4400
# แล้วเปิด http://localhost:4400
```

---

## 2. ค่าใช้จ่ายในการเผยแพร่

| ทางเลือก | ค่าโฮสต์ | หมายเหตุ |
|---|---|---|
| **Cloudflare Pages** (แนะนำ) | **฿0 ตลอดไป** | แบนด์วิดท์ไม่จำกัด มี CDN ในสิงคโปร์ เร็วสำหรับผู้ใช้ไทย |
| Netlify / Vercel (แผนฟรี) | ฿0 | แบนด์วิดท์ 100 GB/เดือน เพียงพอสำหรับเว็บธุรกิจทั่วไป |
| GitHub Pages | ฿0 | ต้องใช้ repo แบบ public |
| **ชื่อโดเมน .com** | ~฿350–450/ปี | ค่าใช้จ่ายเดียวที่จำเป็นจริง ๆ |
| **รวมต่อปี** | **~฿400** | เทียบกับเว็บ SSR + ฐานข้อมูล ที่มีค่าใช้จ่าย ฿700–2,000/เดือน |

### วิธีขึ้น Cloudflare Pages (ประมาณ 5 นาที)

1. สมัครที่ https://dash.cloudflare.com → เลือก **Workers & Pages** → **Create** → **Pages**
2. เลือก **Upload assets** แล้วลากโฟลเดอร์ `epoxy-site` ทั้งโฟลเดอร์เข้าไป
   (หรือเชื่อมกับ GitHub แล้วตั้ง Build output directory = `epoxy-site`, Build command = เว้นว่าง)
3. กด Deploy → ได้ลิงก์ `ชื่อโครงการ.pages.dev` ใช้งานได้ทันที
4. เมื่อซื้อโดเมนแล้ว ไปที่ **Custom domains** เพื่อผูกโดเมน (ใบรับรอง HTTPS ออกให้ฟรีอัตโนมัติ)

## 3. ตั้งค่าฟอร์มขอใบเสนอราคา ⚠️ **สำคัญที่สุด**

**ตอนนี้ฟอร์มยังส่งไม่ได้** และจะแจ้งลูกค้าตรง ๆ ว่ายังส่งไม่ได้ พร้อมบอกให้โทรหรือทัก LINE แทน
(ตั้งใจให้เป็นแบบนี้ — ดีกว่าบอกว่า "ส่งสำเร็จ" ทั้งที่ไม่มีใครได้รับ แล้วเสียลูกค้าไปเงียบ ๆ)

วิธีเปิดใช้งาน:

1. สมัครฟรีที่ https://web3forms.com (ไม่ต้องใช้บัตรเครดิต ส่งได้ 250 ข้อความ/เดือน)
2. กรอกอีเมลที่ต้องการรับข้อความ → ระบบจะส่ง **Access Key** มาให้
3. เปิด `index.html` หาบรรทัดนี้ (อยู่ประมาณบรรทัด 108)

   ```html
   <form id="quoteForm" novalidate data-endpoint-key="">
   ```

   แล้วใส่ key ลงไป:

   ```html
   <form id="quoteForm" novalidate data-endpoint-key="xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx">
   ```

4. อัปโหลดใหม่ แล้ว**ทดสอบส่งฟอร์มจริงหนึ่งครั้ง** เพื่อยืนยันว่าอีเมลเข้าจริง

> อยากให้เด้งเข้า LINE แทนอีเมล ใช้ LINE Notify หรือ Telegram Bot ก็ได้
> โดยแก้ URL ปลายทางใน `main.js` ฟังก์ชัน `fetch(...)`

## 4. รายการที่ต้องแก้ก่อนเผยแพร่จริง

ข้อมูลด้านล่างเป็น **ตัวอย่างสมมติทั้งหมด** ต้องแทนที่ด้วยข้อมูลจริงก่อนเปิดเว็บ
ใช้ฟังก์ชัน "ค้นหาและแทนที่" ในโปรแกรมแก้ไขข้อความได้เลย

| ค้นหา | แทนที่ด้วย | อยู่ในไฟล์ |
|---|---|---|
| `081-234-5678` | เบอร์โทรจริง | index.html, main.js |
| `0812345678` | เบอร์จริงแบบไม่มีขีด (ใน `tel:`) | index.html, main.js |
| `+66812345678` | เบอร์จริงรูปแบบสากล (ใน JSON-LD) | index.html |
| `@epoxypro` | LINE ID จริงของร้าน | index.html, main.js |
| `EPOXY PRO` / `บริษัท อีพ็อกซี่ โปร จำกัด` | ชื่อจริง | index.html |
| `https://example.com` | โดเมนจริง | index.html (canonical, og:url, JSON-LD) |
| `sales@example.com` | อีเมลจริง | index.html |
| `99/9 หมู่ 5 ถนนเทพารักษ์…` | ที่อยู่จริง | index.html (footer + JSON-LD) |
| `0000000000000` | เลขประจำตัวผู้เสียภาษี | index.html |

**นอกจากนี้ต้องตรวจ:**

- [ ] **ราคาในหัวข้อ "ราคาเริ่มต้น"** — ตัวเลข ฿250–450 / ฿550–900 / ฿750–1,500 เป็นตัวอย่าง
      ต้องแก้ให้ตรงกับต้นทุนจริง **มิฉะนั้นจะผูกพันทางการค้า**
- [ ] **ตัวเลขในแถบความน่าเชื่อถือ** — 400+ โครงการ, 15 ปี, รับประกัน 2 ปี
      ถ้าไม่ตรงความจริงให้แก้หรือเอาออก (โฆษณาเกินจริงมีความผิดตาม พ.ร.บ. คุ้มครองผู้บริโภค)
- [ ] **เนื้อหาคำถามที่พบบ่อย** — โดยเฉพาะเงื่อนไขการรับประกันและการวางมัดจำ
- [ ] **รูปภาพ** — ดูข้อ 5

## 5. ใส่รูปผลงานจริง

ตอนนี้ช่องรูปในหัวข้อ "ผลงาน" เป็นพื้นหลังไล่สีที่วาดด้วย CSS (ไม่มีไฟล์รูป เว็บจึงโหลดเร็วมาก)
เมื่อมีรูปงานจริงแล้ว ให้แทนที่แต่ละ `<figure class="shot ...">` ด้วย:

```html
<figure class="shot">
  <img src="assets/warehouse-samutprakan.webp"
       alt="พื้นอีพ็อกซี่โกดังสินค้า 1200 ตารางเมตร จังหวัดสมุทรปราการ"
       loading="lazy" width="800" height="600"
       style="position:absolute;inset:0;width:100%;height:100%;object-fit:cover">
  <figcaption class="shot__cap">โกดังสินค้า 1,200 ตร.ม. จ.สมุทรปราการ
    <small>Epoxy Coating · ส่งมอบใน 4 วัน</small></figcaption>
</figure>
```

**ข้อควรระวังเรื่องความเร็ว** — รูปจากมือถือมักมีขนาด 3–5 MB ซึ่งจะทำให้เว็บช้ามากบน 4G
ก่อนอัปโหลดให้ย่อขนาดทุกครั้ง:

1. เข้า https://squoosh.app (ฟรี ไม่ต้องติดตั้ง)
2. เลือกรูป → ตั้งค่า **WebP คุณภาพ 75** → ปรับความกว้างเหลือ **1600 px**
3. ไฟล์ควรเหลือประมาณ **150–250 KB ต่อรูป**

เคล็ดลับการขาย: ถ่ายรูป **ก่อนทำ** และ **หลังทำ** ในมุมเดียวกัน แล้ววางคู่กัน
ลูกค้างานพื้นตัดสินใจจากรูปคู่แบบนี้มากกว่ารูปสวยเดี่ยว ๆ

## 6. ทำรูป og-image สำหรับแชร์ใน LINE และ Facebook

เวลามีคนส่งลิงก์เว็บในกลุ่ม LINE ระบบจะดึงรูปจาก `og:image` มาแสดง
ตอนนี้ยังชี้ไปที่ไฟล์ที่ไม่มีอยู่จริง ให้สร้างรูปขนาด **1200 × 630 px**
(ใส่โลโก้ + ข้อความ "รับทำพื้นอีพ็อกซี่ ประเมินฟรี" + เบอร์โทร)
บันทึกเป็น `assets/og-image.jpg` แล้วแก้ path ใน `<meta property="og:image">`

## 7. หลังเผยแพร่ ให้ทำ 3 อย่างนี้

1. **Google Business Profile** — https://business.google.com สมัครฟรี
   สำหรับธุรกิจรับเหมาในไทย ช่องทางนี้มักสร้างลูกค้าได้มากกว่า SEO ของเว็บเอง
   ใส่ชื่อ ที่อยู่ เบอร์โทร **ให้ตรงกับในเว็บเป๊ะ ๆ** แล้วอัปรูปผลงานสัปดาห์ละครั้ง
2. **Google Search Console** — https://search.google.com/search-console
   ยืนยันความเป็นเจ้าของ แล้วส่ง URL เพื่อให้ Google เก็บข้อมูลเร็วขึ้น
3. **ตรวจความเร็ว** — https://pagespeed.web.dev
   ทดสอบด้วยโหมด Mobile ควรได้คะแนน 90 ขึ้นไป ถ้าต่ำกว่านั้นมักมาจากรูปที่ใหญ่เกินไป
